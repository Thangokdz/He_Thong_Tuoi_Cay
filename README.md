# He_Thong_Tuoi_Cay

## Description
This project is an IoT-based smart irrigation system that automatically waters plants based on soil moisture levels. The system monitors environmental conditions and controls a water pump to maintain optimal soil moisture.

## Features
- Measure soil moisture using soil sensor
- Detect rain conditions (optional rain sensor)
- Automatically control water pump via relay
- Display system status on LCD
- Servo control for water direction (optional)

## Hardware Components
- Arduino Uno
- Soil Moisture Sensor
- Rain Sensor
- Relay Module
- Water Pump (DC Motor)
- LCD 16x2
- Servo Motor
- Battery (9V)
- Breadboard & jumper wires

## Working Principle
The soil moisture sensor continuously measures the moisture level of the soil.

- If soil is dry → system activates water pump
- If soil is wet → system stops watering
- Rain sensor helps avoid watering during rain
- LCD displays system status in real-time
